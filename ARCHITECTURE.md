# Architecture

This repository composes a personal Guix System and Guix Home configuration.

## Ownership

- `channels.scm` pins the package and module sources.
- `systems/base-system.scm` owns shared machine policy; `systems/T450s.scm`
  and `systems/X1.scm` supply hardware, filesystems and host-specific services.
- `home/samuel-home-configuration.scm` assembles the desktop environment;
  `home/samuel-wsl2-home-configuration.scm` provides the portable WSL2 variant.
- `home/packages/base-packages.scm` owns package groups and the desktop/WSL2
  assemblers. Custom package recipes live beside it.
- `home/services/` owns application settings generated by Guix. For example,
  Helix's configuration is generated by `helix.scm` and `helix-home-services.scm`.
- `home/files/` holds application-owned files installed by the dotfiles service,
  including Emacs and Eww. Do not generate the same target from a service too.
- `home/lib/` holds shared helpers for identity, mail identity and Git hooks.
- `scripts/` holds Guile workflow programs. The Guile-only rule applies to this
  directory; application and skill tooling can use their required languages.
- `.agents/skills/` holds agent workflows; `docs/` retains investigations and
  historical audits, which may describe configurations since removed.

## Evaluation and installation

Run `make update` for channel pull, system reconfiguration and home
reconfiguration. Individual targets are `make pull`, `make reconfigure-system`
and `make reconfigure-home`. Reconfiguration uses `guix time-machine -C
channels.scm` and the matching `home/` or `systems/` load path. See `README.org`
for machine setup and `QA.md` for checks before reconfiguring.

Minde normally comes from the verified binary pinned in `minde-binary.lock.scm`.
`minde-package.scm` exposes it as a package, and `make minde-install` imports it.
`MINDE_BUILD_LOCAL=1` explicitly selects development builds from the sibling
checkout. Personal desktop policy and all Print-prefix bindings belong in
`home/services/minde.scm`; Emacs keys belong in `keybindings-conf.el`.

The terminal is Foot, with Konsole also installed. Agent launchers share
`scripts/lib/agent-launch.scm`; individual launchers choose their execution mode.
Claude defaults to a host Guix shell, with container mode explicitly selectable.

Passwordless hardware controls run immutable programs installed under
`/etc/system-scripts/` by `systems/privileged-scripts.scm`. Editing their source
requires a system reconfiguration before it affects the running machine.

## External sources

Some packages and services still use sibling checkouts or private local data.
See the installation notes in `README.org` and each owning module. A successful
local dry run does not prove that an otherwise empty machine has those sources.
